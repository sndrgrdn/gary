# Omarchy shell parity for Gary

This note lists every user-facing shell feature that Omarchy ships and maps each one to Gary. For each feature it says whether Gary has it, whether one of the ten plugins in progress covers it, or whether it is missing. For a missing feature it names the Gary kind and capability that would carry it, or the Gary gap that blocks it.

## Sources

Omarchy ships two shell stacks, so this note reads both at pinned release tags:

- **v3.8.4** at [`8fcc9d6`][v3], released 2026-07-20. This is the classic stack: Waybar, Walker with Elephant, Mako, SwayOSD, Hyprlock, Hypridle, Hyprsunset, and the bash `omarchy-menu`.
- **v4.5.0** at [`ac2690c`][v4], released 2026-11-04. Here one Quickshell process, `omarchy-shell`, replaces Waybar, Walker, Mako, SwayOSD, Hyprlock, Hypridle, and the polkit agent with first-party plugins ([plugin table][v4-plugins]). `config/` at this tag has no `waybar`, `walker`, or `swayosd` folder. The menu is now a JSONC tree ([`omarchy-menu.jsonc`][v4-menu]).

The default branch `quattro` was at `c1e3553` (2026-11-22) when this note was written. No citation below comes from that branch.

Gary evidence is local:

- `gary skill show` from the installed `gary 0.1` (`/opt/homebrew/bin/gary`), and `Sources/gary/SkillGuide.swift` and `Sources/gary/Capabilities/*.swift` at Gary `686c913`.
- Existing plugins: `~/Developer/gary-plugins` at `e537e9e` (`sndrgrdn.dinky`, `front-app`, `weather`, `battery`, `clock`, `theme`), enabled in `~/.config/gary/shell.json`.
- The plugins in progress are on branches with worktrees under `~/Developer/worktrees/gary-plugins/`: `calendar`, `clipboard`, `control-center`, `focus-timer`, `launcher`, `now-playing`, `system-load`, `tray`, and `weather-forecast`. The volume and brightness OSD belongs to `control-center`. Their scope comes from the task description, and this note does not verify it against their code.

### What Gary offers

- Kinds: `bar-widget`, `bar`, `panel`, `overlay`, `menu`, `service` (`SkillGuide.swift:42-49`). A panel, overlay, or menu can have several named surfaces, a `layer` (`desktop`, `below`, `normal`, `top`, `overlay`, `notch`), and `keepLoaded`.
- Manifest `hotkeys`. A combination needs `cmd`, `ctrl`, or `alt`, unless its key is `f1` to `f12` (`SkillGuide.swift:142`).
- 22 capabilities: `apps`, `audio`, `battery`, `bluetooth`, `brightness`, `clipboard`, `clock`, `dock`, `exec`, `files`, `focus`, `mediakeys`, `menubar`, `network`, `notifications`, `nowplaying`, `paste`, `permissions`, `session`, `tray`, `wallpaper`, `wifi` (`Sources/gary/Capabilities/*.swift`, the `summary:` line of each file).
- Plugins reach each other only through `host.publish` and `subscribes`, and `host.call` reaches only the plugin's own `methods` (`SkillGuide.swift:227`). `gary call <plugin> <method>` from a shell reaches any plugin. `exec` puts Gary's own executable folder first on the PATH (`Sources/gary/Capabilities/Exec.swift:130`), so a plugin can run `gary call` against another plugin. This is a workaround, not an API.

## Feature map

Status values:

- **Has**: an existing plugin covers it.
- **Building**: one of the ten plugins in progress covers it.
- **Partial**: part of it exists or is in progress.
- **Missing**: nothing covers it yet, and Gary can carry it.
- **Blocked**: missing, and a Gary gap stops a faithful version.
- **N/A**: macOS owns it, or it only matters on Linux.

## Gary gaps that block features

Ordered by how many features each gap blocks:

1. **No notification posting and no cross-plugin call.** This blocks info toasts, action toasts, low battery alerts, and reminders. `gary call` through `exec` works around it.
2. **No long-lived process API, and `exec` stops a command after 60 seconds.** This blocks screen recording, stay awake, and any helper daemon (`Exec.swift:94-98`).
3. **No screen capture, sampling, or Vision capability.** This blocks the color picker, OCR, and QR decoding (`grep` of `Sources/` finds no `SCScreenshotManager`, `NSColorSampler`, or `VNRecognizeText`).
4. **`notifications` and `focus` are read-only.** This blocks dismissing notifications and toggling DND.
5. **`mediakeys` covers five keys only.** This blocks the media key, mic mute key, and keyboard backlight key OSDs.
6. **Missing system capabilities:** idle time, Night Shift, keyboard backlight, input source, display configuration, and per-app volume.
7. **No host API for the bar or the plugin registry.** This blocks the hide-bar toggle and the keybinding cheat sheet.
8. **Inference:** Automation permission (Apple Events) is missing from Gary's permissions list. Power menu actions through System Events would trigger a prompt that `gary permissions` cannot explain.

## Top five missing features by daily value

This ranking is a judgment. It weighs how often a feature would be used against how well macOS already covers it.

1. **Omarchy menu with the system and power menu.** It is one keyboard entry point for lock, sleep, restart, toggles, capture, theme, and links. Carrier: `menu`, `exec`, and `hotkeys`. Nothing blocks the core. Power actions may trigger the Automation prompt.
2. **Toast plugin.** It shows quick time, battery, and weather toasts, the low battery alert, reminders, and the "screenshot saved" toast. Carrier: a `panel` with a `keepLoaded` toast surface and `methods.notify`, reached through `exec gary call`. This would exercise multi-surface panels and the missing cross-plugin path.
3. **Audio output picker and microphone mute.** This extends `control-center` for switching to AirPods or a headset. Carrier: `audio.setDefaultDevice()` and `audio.setMuted(…, "input")`. The mic key itself is blocked by the `mediakeys` gap.
4. **Notification history with a DND indicator.** Carrier: a `panel` with `notifications` and `focus`, which needs Full Disk Access. Dismissing notifications and toggling DND stay blocked.
5. **Capture menu.** A region screenshot to the clipboard or a file works through `exec screencapture`. The color picker, OCR, and QR decoding are blocked by gap 3, and recording by gap 2.

Runners-up: the keybinding cheat sheet, the AI agent usage panel, stay awake, the emoji picker, the world clock, and the update indicator.

## Uncertainty

- The status of the ten plugins in progress comes from the task description and branch names, not from their code. For example, whether `launcher` includes calculator or file search is unknown.
- These claims are inferences that no one has tested: `screencapture` uses Gary's Screen Recording grant, a backgrounded grandchild of `exec` survives, JavaScriptCore supports `Intl` time zones, and System Events triggers an Automation prompt.
- Omarchy v4's default branch moves fast. Features added after v4.5.0 are not covered.
