# Gallery

A panel that shows Gary's drawing features: a gradient `background`, a `shape` progress ring whose `trim` animates when you click it, `chart` sparklines, a 7-column `grid` calendar, a looping pulse and spin, `rotation`, `blur` and `blend`, and a `shader` that draws `glow.metal`.

Copy it with `gary plugin new you.gallery --from gallery`, and open it with `gary toggle you.gallery`.
