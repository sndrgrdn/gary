# Timer

A panel with a countdown timer. The slider sets the length from 5 to 60 minutes, and Gary keeps the length in the plugin's storage. Start and Stop run the countdown, and the panel shows itself again when time is up. `keepLoaded` keeps the countdown running while the panel is hidden, and `animation: "smooth"` moves the progress bar and the slider smoothly when they change.

Open it with `gary toggle example.timer`.
